# Destination photography

`DestinationShowcase` (used in the hero) looks for these exact files.
Until they exist, it shows a tasteful gradient fallback instead of a
broken image — so the layout is safe to run before you add photos.

| File | Suggested shot |
| --- | --- |
| `rajasthan.jpg` | Udaipur lake palace / havelis, golden hour |
| `kerala.jpg` | Alleppey backwaters houseboat |
| `kyoto.jpg` | Kyoto temple street, traditional architecture |
| `goa.jpg` | Baga/Goa coastline, beach |
| `himalayas.jpg` | Manali mountain valley |
| `bali.jpg` | Ubud rice terraces |

Recommended size: at least 1200×1500px (portrait), landscape/travel
photography, natural light. Free sources with permissive licenses:
Unsplash (unsplash.com) and Pexels (pexels.com) — search each
location name above.

To add or change a destination, edit `src/data/destinations.ts` and
drop the matching file here.
