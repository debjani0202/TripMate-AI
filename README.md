# ✈️ TripMate AI

> An AI-powered travel planning application that generates personalized travel plans based on destination, budget, interests, travel style, and trip duration.

TripMate AI combines a modern React frontend with a FastAPI backend and a multi-agent AI travel planning workflow powered by CrewAI.

The project is being developed with a focus on real-time AI agent progress, structured travel-plan generation, and a clean user experience.

---

## 🌟 Project Overview

TripMate AI allows users to enter their travel preferences and generate a personalized itinerary.

The application is designed around the following flow:

User
  ↓
React Frontend
  ↓
